## 1. Collecte des déchets – Théorie des graphes

Ce projet consiste à développer une application permettant d'optimiser l'organisation de la collecte des déchets en utilisant les concepts de **théorie des graphes** et différents algorithmes d'optimisation.

### Fonctionnalités principales

- Représentation d'un réseau routier sous forme de graphe
- Calcul des plus courts chemins
- Optimisation des tournées de collecte
- Planification des collectes selon différentes contraintes
- Étude et comparaison de plusieurs algorithmes de théorie des graphes
- Interface utilisateur en mode console

### Algorithmes étudiés

- Plus court chemin
- Voyageur de commerce (TSP)
- Arbre couvrant de poids minimum (MST)
- Parcours eulérien
- Coloration de graphes
- Heuristique du plus proche voisin

### Technologies utilisées

- Java
- Programmation Orientée Objet (POO)
- UML
- Théorie des graphes

Le projet est entièrement documenté dans le dossier **CollecteDechets/**.
