## 1. Waste Collection Optimization – Graph Theory

This project focuses on developing an application that optimizes waste collection routes using **graph theory** concepts and various optimization algorithms.

### Main Features

- Road network representation as a graph
- Shortest path computation
- Waste collection route optimization
- Collection scheduling under different constraints
- Study and comparison of several graph theory algorithms
- Console-based user interface

### Algorithms Studied

- Shortest Path
- Traveling Salesman Problem (TSP)
- Minimum Spanning Tree (MST)
- Eulerian Path
- Graph Coloring
- Nearest Neighbor Heuristic

### Technologies Used

- Java
- Object-Oriented Programming (OOP)
- UML
- Graph Theory

The project is fully documented in the **WasteCollection/** folder.
